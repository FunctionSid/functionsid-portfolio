# Project Context

## Overview
This repository contains the source code, visual assets, and documentation for the personal portfolio website of **Siddharth Dilip Kalantri**.

- **Owner:** Siddharth Dilip Kalantri
- **Location:** Bhiwandi, Maharashtra, India
- **Role:** Accessibility Engineer, Full-Stack Developer, AI Enthusiast
- **Primary Personal Story:** Siddharth holds a B.Sc. in Drugs & Dyes Chemistry from BNN College, Bhiwandi. After working in his family flour mill business and pursuing a diploma in Flour Milling Technology at ISMT, a retinal detachment led to glaucoma and gradual complete loss of vision in both eyes over 5–7 years. Adapted by mastering assistive technologies (NVDA and JAWS screen readers with 20+ years of experience). Self-taught software developer starting around 2022, specializing in web development, accessibility engineering, AI/RAG models, database design, and cloud infrastructure.

## Project Purpose
To create an accessible, high-performance, responsive portfolio website that showcases Siddharth's projects, skills, certifications, blog write-ups, personal journey, and accessibility statement.

## Key Objectives
- **Target Standard:** WCAG 2.2 Level AA compliance.
- **Screen Reader Support:** Full compatibility with NVDA and JAWS screen readers.
- **Keyboard Operability:** 100% keyboard navigable with visible focus states.
- **Infrastructure Efficiency:** Designed to run reliably on a low-memory Oracle Cloud Infrastructure (OCI) Linux VM.
- **Security:** Secret isolation using environment variables and dedicated database application schema.

## Key Projects to Feature
1. **LawGPT (Legal RAG Chatbot):** AI-powered RAG assistant for Indian legal documents (Constitution of India & BNS 2023) in simple English with inline citations.
2. **AgriQuery (Agriculture RAG Chatbot):** Natural language chatbot for real-time agricultural commodity prices powered by government APIs (data.gov.in).
3. **A11Y Insights:** Awareness platform promoting digital accessibility and inclusive web development.
4. **DECtalk for NVDA 2026.1 Compatibility:** NVDA add-on modernization for 64-bit NVDA 2026.1 speech synthesizer compatibility.
5. **Stream-Ripper (NVDA Add-on):** NVDA add-on providing a searchable command palette for screen reader user productivity.
